# 3D Inspect 0.4

Обмеры для ремонта: необязательная калибровка по лазерной рулетке, независимые контрольные размеры,
площадь вертикальных стен, ведомость CSV и GLB с новым масштабом. На карте MPUNAV можно перетаскивать
слой скана, поворачивать и масштабировать его, измерять длины и площади и сохранять наложение.
Один контрольный размер исправляет единый масштаб, но не локальный дрейф или искажения схематического
SVG; точность обмера не объявляется подтверждённой автоматически.

Локальная программа для проектов, анализа сканов, измерений и привязки к SVG MPUNAV.
Python-бэкенд, браузерный интерфейс, CUDA на NVIDIA GPU. Без Docker и загрузки сканов на внешний сервер.

## Запуск

`Запустить 3D.bat` открывает программу. `Закрыть 3D.bat` выключает только её сервер.
Первый запуск без подготовленного окружения требует Python и установки `desktop/requirements.txt`.
Для CUDA: `desktop/requirements-gpu.txt`. На компьютере пользователя окружение уже подготовлено.

## Возможности

- Создание и сохранение проектов, исходных GLB/LAS/ZIP и измерений.
- Совместный импорт GLB + LAS одного скана, импорт каждого формата отдельно.
- Обработка по кнопке: локальные координаты LAS, поиск поворота и ICP, CUDA-объединение точек и поиск плоскостей.
- Обработка v2 с сохранением UV и текстуры, согласованным движением швов и проверками деформаций.
- Один ракурс для исходного и обработанного результата, ползунок сравнения, карта изменений, архив v1.
- Расстояния, ломаные, площадь проекции, габариты объекта, выделенного рамкой и глубиной.
- PNG/JPG/PDF-планировка: локальный OCR, линии, предложение масштаба, условная 3D-модель стен.
- Каталог SVG MPUNAV, привязка по двум точкам, контроль третьей, отдельный экспорт SVG со слоем скана.
- Палитра и Gilroy по образцу mpunav.ru. Шрифты загружаются в локальную установку через `desktop/get_fonts.py` и не включены в этот репозиторий.

Все пользовательские данные в `data/` исключены из Git. Порядок работы и рекомендации: [Памятка.md](Памятка.md).

## Ограничения

Это рабочая программа анализа сканов, но не сертифицированный обмерный инструмент.
Точность 3 см не гарантируется без независимых контрольных замеров.
Геометрическая обработка не является обученной нейросетью и не исправляет крупный дрейф или пропуски.
Мебель автоматически не распознаётся и не заменяется идеальной CAD-геометрией.
OCR-план и его масштаб требуют проверки, стены условной высоты и толщины.
MPUNAV-привязка не меняет исходный сайт, топологию SVG и граф маршрутов; экспорт добавляет отдельный слой скана.
Автоматического объединения нескольких проходов и полноценного BIM пока нет.

Нативный iPhone-сканер первой версии остаётся в `ios/`. Его сборка была проверена на macOS через GitHub Actions;
проверка съёмки на физическом iPhone ещё не выполнена. Для текущего рабочего процесса используется Scaniverse Classic.


## Планировка и видимость стен (0.4)

Раздел «Планировка» строит метрическое сечение наблюдаемых архитектурных стен из GLB. Экспорт: SVG A3 с размерными линиями, DXF с координатами и размерными числами в миллиметрах, CSV фрагментов, JSON диагностики. Высота сечения и масштаб листа задаются пользователем. Разрывы остаются неизвестными: проём, мебель или пропуск съёмки требуют проверки. Концы незамкнутого скана не достраиваются. Это черновик обмера; соответствие ГОСТ/СПДС не подтверждено.

Боковые стены можно скрывать все вместе, по отдельной галочке или щелчком в 3D. Скрытие меняет только просмотр и выбор видимых поверхностей. Исходные файлы и экспорт сохраняют стены.

Наложение MPUNAV поддерживает раздельные длину и ширину слоя. Это подгонка схемы, не изменение размеров 3D; замеры SVG используют обратное преобразование обеих осей.

Необязательный `data/default-calibration.json` задаёт предварительный профиль прошлого скана. Новый проект получает копию профиля. Ручная калибровка текущего скана имеет приоритет, сброс возвращает исходный масштаб и отключает базовую поправку. Источники и остаточные расхождения должны сохраняться в профиле. Профиль не включён в публичный репозиторий.


### Импорт Polycam

Поддерживаются GLB с несколькими частями и текстурами, а также сжатые облака LAZ (через lazrs). Обработка учитывает все части с сохранением UV, материалов и изображений. Неединичные преобразования узлов пока отклоняются при регуляризации. В просмотре для фотоматериалов без заданного metallicFactor отключён неявный металл; экспорт сохраняет оригинальные свойства. Карта изменений строится для всех частей. Общая выборка для наложения ограничена примерно 6000 точек на всю модель.

### Свободная камера и однотонный просмотр

В меню «Режим камеры» выбери «Свободное движение внутри 3D», затем щёлкни по просмотру. WASD — движение в направлении камеры, Q/E — вниз/вверх, Shift — ускорение, правая кнопка и мышь — осмотр, Esc — возврат. Камера проходит сквозь поверхности; столкновения не моделируются. «Вписать», «Сверху» и выбор измерительного инструмента возвращают обычную камеру. Клавиши действуют только при фокусе на 3D, потеря фокуса останавливает движение.

«Однотонный вид» заменяет фотоматериалы матовым серым только для просмотра. Геометрия, выбор точек, измерения и экспорт не изменяются. Карта изменений и облако точек сохраняют собственные цвета. Для облака из экспорта Polycam не подтверждён статус сырых LiDAR-измерений: плотность точек не доказывает физическую точность.
