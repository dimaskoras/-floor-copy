# Floor Copy

Первая версия собственного LiDAR-сканера для iPhone и локального просмотра на Windows.
Цель проекта: проверенная цветная модель этажа. Текущая версия обрабатывает **один непрерывный участок**.
Точность 3 см пока не подтверждена. Ни размер вокселя, ни ровные плоскости сами по себе не доказывают точность.

## Что уже реализовано

- Нативный сканер ARKit: карта глубины в метрах, confidence, фото, калибровка камеры, позы, временные метки.
- Пространственная сетка ARKit с обнаружением горизонтальных и вертикальных плоскостей.
- ZIP-экспорт измерений через системное меню «Поделиться» и приложение «Файлы».
- Локальная обработка на Windows: фильтрация ненадёжной глубины, объединение цветных точек, перенос цвета на сетку.
- Просмотр сетки и точек, вид сверху, измерение двух точек, экспорт GLB и PLY.
- Прямой импорт Scaniverse GLB с фототекстурами.
- Осторожное выравнивание поддержанных плоскостей с пределом сдвига 25 мм; сравнение исходной и обработанной модели.
- CUDA-поиск плоскостей и объединение большого количества исходных RGB-D точек, если доступна NVIDIA GPU.
- Облачная сборка неподписанного IPA через GitHub Actions для последующей подписи Sideloadly.

## Что ещё предстоит

Проверка съёмки нашего приложения на реальном iPhone, собственное построение фототекстур, поиск пропусков,
совмещение участков и замыкание траектории, контрольные размеры, параметрическое редактирование стен
и полный план этажа. RoomPlan пока не подключён.
Цветная сетка в версии 0.1 использует цвета вершин, а не полноценный атлас фототекстур.
Выровненная ARKit-сетка может отличаться от исходных измерений; точки сохраняются отдельно.

## Установка на iPhone без своего Mac

1. Открой репозиторий на GitHub → Actions → **Build iPhone app**. После завершения скачай артефакт **FloorCopy-iPhone**.
2. Распакуй скачанный ZIP: внутри находится `FloorCopy-unsigned.ipa`.
3. Установи [Sideloadly](https://sideloadly.io/) на Windows. Используй только официальный сайт и зависимости Apple, которые он указывает.
4. Подключи iPhone по USB, разблокируй и подтверди доверие компьютеру.
5. В Sideloadly выбери IPA и войди в бесплатный Apple Account. Пароль вводится в программу, не в чат.
6. После установки подтверди профиль разработчика в настройках iPhone. При необходимости включи «Режим разработчика» в «Конфиденциальность и безопасность» и перезагрузи телефон.
7. Разреши приложению камеру. Бесплатная подпись действует 7 дней; настрой обновление Sideloadly.

Совместимость установки с iOS 27.0.1 должна быть проверена на устройстве. Если Sideloadly не поддержит эту версию,
готовая облачная сборка сама по себе этого ограничения не устранит. Не покупай сертификаты до проверки.
Приложение не требует аккаунта Apple Developer Program и не использует специальные облачные entitlement.

## Запуск на Windows

### Использование готового бесплатного сканера

Установи [Scaniverse](https://apps.apple.com/app/id1541433223) из App Store. Используй Classic experience,
локальную съёмку **Mesh**, затем экспортируй модель **GLB** со встроенными текстурами и передай её на ПК.
Просмотрщик принимает такой GLB напрямую: текстуры, измерения и вид сверху доступны без установки нашего IPA.
Первый тест сделай на небольшом участке, прежде чем сканировать весь этаж.
Импорт готовой модели не даёт исходных карт глубины, confidence и поз камеры; пересчитать исходную траекторию по одному GLB нельзя.
Gaussian Splat (SPZ или splat PLY) пока не поддерживается нашим просмотрщиком.
Кнопка «Выровнять отклонения до 2,5 см» создаёт отдельный `straightened.glb`, сохраняющий фототекстуры.
Исходная модель остаётся доступна отдельно. Алгоритм ищет плоские поверхности и исправляет небольшие отклонения;
он не восстанавливает пропуски, не гарантирует точность и не исправляет крупную деформацию траектории.
Сдвиг ограничен 25 мм, чрезмерные правки отклоняются, перевёрнутые треугольники откатываются.
В текущей реализации выравнивается один GLB с одной треугольной сеткой без преобразований узлов.
Плоскости мебели не должны автоматически считаться стенами. Привязка к пользовательскому плану требует проверки.

### Ускорение RTX 4060

Для CUDA-объединения исходных RGB-D точек установи `desktop/requirements-gpu.txt` в окружение `.venv`.
При 250 000 точек и больше обработчик использует CUDA, если она доступна; маленькие наборы обрабатываются на CPU.
В `report.json` записывается фактически использованный `fusionBackend`. При нехватке GPU-памяти автоматический режим возвращается на CPU.
Пул CUDA ограничен 3 ГБ. Импорт готового GLB не требует этой реконструкции и не ускоряется данным CUDA-этапом.

Нужен установленный Python 3.11 или новее. Запусти **Start.cmd**. При первом запуске установятся numpy, Pillow и scipy.
Открой `http://127.0.0.1:4318`, если вкладка не открылась автоматически. Сервер доступен только на этом ПК.
Первые загрузка библиотек и сборка iOS требуют интернета. После установки обработка и просмотр работают локально.
Сканы находятся в папке `data/` и исключены из Git. Не добавляй реальные сканы в публичный репозиторий.

## Первая съёмка

1. Выбери участок коридора длиной примерно 5–10 м с дверью и поворотом. Измерь ширину коридора, проём и расстояние между двумя хорошо различимыми точками.
2. Начни «Новый участок». Медленно обойди его, покажи стены, пол, потолок, двери с разных направлений. Не сворачивай приложение.
3. Вернись к началу, если возможно. Пока замыкание траектории не оптимизируется нашим обработчиком.
4. Заверши запись. В одном участке максимум 240 сохранённых кадров, примерно 3 минуты при нормальном отслеживании.
5. Нажми «Экспорт ZIP» → «Сохранить в Файлы». Передай ZIP на ПК через iCloud Drive либо извлеки его через файловый обмен Apple Devices/iTunes.
6. Импортируй ZIP в веб-просмотрщик, сравни измерения с реальными. Если сомневаешься в цветной сетке, переключись на исходные точки.

Сканировать нужно неподвижное окружение при хорошем освещении. Зеркала, стекло, люди и однотонные длинные коридоры ухудшают результат.
При прерывании AR-сессии участок автоматически завершается. Новый участок получает новую систему координат; просто складывать их без регистрации нельзя.
Исходные данные остаются в «Документах» приложения. Удаляй старые участки через «Файлы» только после проверки ZIP на компьютере.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s desktop -p "test_*.py" -v
```

Тесты проверяют оси камеры, матрицы поз, confidence, усреднение точек, GLB и обработку синтетического архива.
Они не подтверждают точность LiDAR в реальном помещении. Компиляция Swift выполняется на macOS через Actions.

## Формат исходных данных

`manifest.json`, `00000.json`, `00000.depth`, `00000.confidence`, `00000.jpg`, …, `mesh.ply`.
Глубина: float32 little-endian, метры; confidence: uint8. Матрицы column-major, transform camera-to-world.
Фото сохраняются в ориентации сенсора. Для восстановления: X вправо, Y вверх, камера смотрит вдоль отрицательного Z.
Привязка цвета к измерениям использует одинаковые координаты сенсора и масштабирование intrinsics до разрешения глубины.
